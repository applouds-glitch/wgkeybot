# Обновление приложения из APK

Оба диалога в `TunnelListFragment` (новая версия и HTTP 426) открывают
`updater/UpdateActivity`. Экран общий для телефона и Android TV.
`AppUpdater` сохраняет текущую операцию при пересоздании Activity, скачивает APK
в приватный кэш, проверяет его и передаёт в `PackageInstaller`.

## Требования к серверу и релизу

- Поле `download_url` в существующем API должно содержать HTTPS-ссылку на сам APK,
  а не страницу релиза. HTTPS-перенаправления поддерживаются (до пяти переходов).
- `latest_version` используется существующим диалогом для обнаружения обновления.
  Перед установкой сравнивается фактический `versionCode` APK: он должен быть выше
  установленного.
- Пакет должен совпадать с установленным приложением. Debug-сборка имеет суффикс
  `.debug`, поэтому обычный release APK не обновляет debug-приложение.
- Подпись должна совпадать или иметь совместимую историю ротации ключа. Окончательную
  проверку подписи и допустимости ротации выполняет Android. Для проверки обновления
  release нужно использовать APK, подписанные одним релизным ключом из CI.
- Предельный размер APK — 256 МиБ. Незавершённая загрузка удаляется. Готовый APK
  сохраняется для повторной попытки установки и возврата из настроек разрешения.

## Поведение Android

На Android 8+ при необходимости открывается разрешение на установку из этого
источника. После выдачи разрешения установка продолжается. При отказе экран
остаётся открытым и позволяет повторно перейти в настройки.

На Android 12+ запрашивается установка без дополнительного подтверждения, с
`UPDATE_PACKAGES_WITHOUT_USER_ACTION`. Если система требует подтверждение,
`PackageInstaller.STATUS_PENDING_USER_ACTION` открывает системный установщик
только из активного экрана. Итог отслеживается через закрытый BroadcastReceiver.
При уходе на домашний экран подтверждение ждёт возвращения в приложение.
Замена APK может завершить процесс приложения и прервать VPN-соединение.

После потери процесса незавершённая сессия заменяется при повторной попытке,
готовый APK проверяется заново. Частичная загрузка начинается сначала; постоянная
фоновая загрузка через foreground service не реализована.

Вариант `googleplay` открывает страницу приложения в Google Play; разрешения,
экран APK-обновления и receiver удалены из его итогового манифеста.

## Проверка на устройстве

1. Установить старую сборку, предложить APK с большим `versionCode`, тем же пакетом
   и подписью. Проверить обновление и сохранность конфигурации.
2. Проверить выдачу и отказ в разрешении на установку, затем возврат из настроек.
3. Проверить системное подтверждение и отмену, повторить без скачивания APK заново.
4. Во время загрузки повернуть экран, свернуть приложение, отменить загрузку;
   повторить после потери процесса.
5. Проверить неверную подпись, другой пакет, старую версию, HTML вместо APK,
   обрыв соединения и HTTPS-перенаправление на HTTP.
6. На Android TV проверить фокус кнопок с пульта и переход в системный установщик.

Локальные проверки: `:ui:assembleDebug`, `:ui:testDebugUnitTest`, `:ui:lintDebug`,
`:ui:processGoogleplayMainManifest`. `UpdatePolicyTest` проверяет допустимость URL,
ротацию ключа вперёд, отказ при обратной ротации и правила нескольких подписантов.
