# Импорт конфигурации из ссылки

Клиент принимает ссылки с полной конфигурацией:

```text
wgkeybot://config?token=<init_token>&data=<payload>
```

`payload` — JSON в UTF-8, сжатый стандартным zlib и закодированный в Base64URL
без `=`. Это кодирование и сжатие, а не шифрование. Ссылка содержит приватный
WireGuard-ключ и токен сессии выбранного устройства.

```json
{
  "version": 1,
  "access_token": "12345678-1234-1234-1234-123456789abc",
  "subscription_expires_at": "2099-09-14T00:00:00Z",
  "config": "[Interface]\n...\n[Peer]\n..."
}
```

На Android и Android TV импорт из ссылки не вызывает API бота: клиент проверяет
payload и WireGuard-конфигурацию, сохраняет сессию и применяет конфигурацию.
Полную ссылку можно вставить в поле подключения или через кнопку вставки на TV.
Расширения `#@wgt:` передаются без изменений. Автообновление через API продолжает
работать по сохранённому `access_token`, начиная со следующего интервала обновления.

Параметр `token` сохраняет совместимость со старыми APK, которые игнорируют `data`
и получают конфигурацию через API. В новом клиенте `data` имеет приоритет: ошибка
в payload не вызывает скрытый переход к запросу по токену. Ссылки без `data`,
обычные токены и прежние ссылки для вставки по-прежнему работают через API.

Ограничения: 32 768 символов на ссылку и 65 536 байт на распакованный JSON.
При распаковке проверяются размер, целостность zlib-потока и отсутствие лишних
байтов. Поддерживается версия 1 с плоским JSON-объектом; вложенные структуры
запрещены. Некорректный payload не сохраняет авторизацию и не показывает ключи
в сообщении об ошибке.

Проверки:

```sh
./gradlew :ui:testDebugUnitTest
./gradlew :ui:assembleDebug
```

`ConnectionLinkTest` включает синтетическую ссылку, созданную Python-генератором
бота, и граничные случаи. `ConnectionImportTest` проверяет применение настоящего
WireGuard-парсера к этой ссылке и сохранность TURN-настроек.
